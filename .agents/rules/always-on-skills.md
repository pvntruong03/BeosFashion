# Always-On Skills Configuration

When Antigravity runs, the following skills are unconditionally active:

1. **`ui-ux-pro-max` + `design-system` + `ui-styling` + `brand`**:
   - Automatically consult design tokens, accessibility rules, color harmony, and UX guidelines on every UI component and page creation/modification.

2. **`understand` + `understand-chat` + `understand-explain` + `understand-domain`**:
   - Automatically analyze codebase architecture, track dependencies between Spring Boot and React, map business domains, and provide full structural clarity.
